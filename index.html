What This Application Does

Modern computer chips are built from many small sections, and each section needs a controlled amount of electricity. Some sections must switch off completely to save battery power. Others must stay awake all the time. Getting this balance right is called power intent, and it is normally one of the most tedious parts of chip design.

power-intent-studio gives you a visual workspace for that job. It shows you the structure of a chip design as a tree you can explore, lets you draw outlines around groups of components to mark them as separate power areas, and lets you fill in a simple table describing when each area is on, off, or partially on. When you are happy with the plan, the application writes out an industry-standard instructions file that other engineering tools can read.

You do not need to be a programmer to use it. Everything happens in a normal window with menus, buttons, and a canvas — the same way you would use a photo editor or a spreadsheet.

Who This Is For

  • Hardware engineers who want to sketch power plans quickly before writing them formally.
  • Students learning low-power chip design who need a visual way to understand the concepts.
  • Team leads who want to review a power structure without opening heavyweight commercial software.
  • Anyone curious about how chips save energy, who prefers clicking over typing.

✨ Main Features

Design Tree Viewer

Open a design file and see its full hierarchy as a collapsible tree. Expand and collapse branches to explore large chips without getting lost.

Power Domain Drawing

Group related components into named power areas by selecting them in the tree. Each area gets a colour so you can recognise it at a glance.

State Tables

Build a simple grid describing which power areas are active in each operating mode. Add or remove rows with a click.

UPF and CPF Output

Export your finished plan as a standard power intent file that downstream tools can consume, ready for review or further refinement.

Liberty Library Awareness

Load cell library information so the application understands which components support power gating and which do not.

Multi-Language Design Support

Work with designs written in SystemVerilog, Verilog, or VHDL without converting anything first.

💡 Tips for a Smooth Start

  • Give every power domain a clear, descriptive name. Future you will thank present you.
  • Start with a handful of large domains rather than dozens of tiny ones. It is easier to split a group later than to merge many small pieces.
  • Keep your design files and your power intent files in the same folder so the application can find related information quickly.
  • Use the zoom controls on the canvas when a design becomes busy. A wider view helps you spot boundaries you might otherwise miss.
  • Save often. Each save creates a snapshot you can return to if an experiment does not work out.

🛠️ If Something Does Not Work

Most problems have a simple cause. If the application will not open, check that you launched it from the folder you downloaded into rather than from inside a compressed archive. If a design file will not load, confirm that the file is not still open in another program. If the window looks cramped, maximise it or increase your screen resolution.

❓ Common Questions

Do I need to know how to program?

No. The whole point of the application is to replace typed instructions with a visual workspace. If you can use a file menu and click on items in a list, you can use this tool.

Will it change my original design files?

No. The application reads your design so it can draw the structure for you. Your power intent is saved separately, so your original files stay exactly as they were.

Can I share my power plan with someone else?

Yes. The exported files are standard formats that other engineering tools understand, so you can hand them to a colleague or open them in your wider design flow.

How large a design can it handle?

Comfortable everyday designs with hundreds of components work smoothly. Extremely large designs will open and display, but exploring them is easier on a machine with 16 GB of memory.
